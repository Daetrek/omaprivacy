# Changelog

All notable changes to OmaPrivacy are documented here.

## 1.0.1

- Added a visible Close button to the panel header and fixed the Escape-key
  shortcut so it actually closes the panel.

## 1.0.0

- Added the Overview protection grid and actionable Findings inbox.
- Added reversible Normal, Meeting, Private, and Lockdown privacy presets.
- Added Browser Location Shield with separate system, precise-browser,
  saved-grant, and IP-estimate reporting.
- Added per-app microphone, camera, and screen-sharing rules with Default,
  Always alert, and reactive Auto-stop modes.
- Added persisted Chromium-family, Firefox-family, and Zen permission review
  and guarded revocation with profile backups.
- Added capture history, alerts, network exposure checks, and optional Lockdown
  automation for session locks and untrusted Wi-Fi.
- Added a one-shot capture-state lock animation and safe plugin-only reload.
- Added recovery for interrupted Location Shield setup and compatibility with
  older configuration and Privacy Mode state files.
- Removed legacy playback false-positive events and obsolete demo UI remnants.
